# AdobeCCBottle
Adobe Creative Cloud Running in a Bottle

This is a backup of a Bottle I created with Google Antigravity using Gemini 3.1 Pro High. It took a couple days and once it got to a working state, I tried to recreate it from scratch. Having the AI create a configuration guide as we went. It was going slower than I expected and I decided to upload the working bottle here for someone with more time and energy to devote... I will continue working on it but I have a full-time job and don't have a lot of free time.

Sometimes the Creative Cloud Desktop will stop responding to mouse clicks. The workaround is to run "C:\Users\Jeremy\Desktop\Launch_Creative_Cloud.bat" from the command line. It will launch and close. Leave the command prompt open, and then you can press the Play button on Creative Cloud Desktop and it should work. You'll need to do this to reinstall Premier. I had to uninstall it to get the file size small enough to upload here. I made a video of me using Premier to see how badly it works and what needs fixing.

I'm uploading a file created by the AI with steps to create the bottle from scratch. The guide is incomplete. Additional undocumented steps are required to get to the state of the bottle provided here. I can verify most of steps 1-5 are correct in getting the installer to work. With the exception that a virtual desktop isn't required. It's there because I was using it for troubleshooting. The remaining steps in guide are unverified. 

Apologies for the incompleteness of my work here. I've been on this for two days and don't have any more time for a while. I want to give someone the opportunity to make this better and help the community run Creative Cloud on Linux. Clearly Adobe will never prioritize it.
