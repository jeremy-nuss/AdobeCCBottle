# AdobeCCBottle
Adobe Creative Cloud Running in a Bottle
These are backups of two Bottles I created. One that has Adobe Creative Cloud Desktop working with Adobe Premier. The other configured to allow Adobe Creative Cloud to be installed with a setup file downloaded directly from Adobe. 

I used Google Antigravity with Gemini 3.1 Pro High to work through the configuration. Below are it's initial steps to get the bottle configured to the "Launch Adobe CC Installer (pre-login)" Bottle. 

My initial plan was to have it create a step-by-step guide by walking me through creating an identical Bottle from scratch, but I quickly realized that was going to take just as long as doing it the first time. I will continue working on this myself, but wanted to provide these bottles to anyone who is more skilled in this type of work and who may fine it valuable.

Please take it and improve on it. There is no reason Creative Cloud shouldn't run on Linux.
